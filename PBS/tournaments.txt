# Each tournament is data-driven.
#
# Required:
#   Name
#   Participants
#
# Optional:
#   Description
#   Mode              = PRESET or RANDOM
#   PlayerSlot        = 1-8
#   Pool              = comma-separated trainer IDs for RANDOM tournaments
#   EntryCount        = currently 8
#   HealBetweenRounds = true/false
#
# PresetWinnerXY means:
#   X = round number (1 = quarterfinals, 2 = semifinals)
#   Y = match number within that round
#
# Value is the entrant ID that must win that NPC-only match.
#
# The player's own matches are NEVER forced by PresetWinner fields.
#===============================================================================
